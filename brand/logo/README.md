# Логотип GitSight

Знак строится на пересечении двух смыслов имени: **Git** (граф коммитов/веток) и
**Sight** (взгляд, «наглядно видно»). Контур — стилизованный глаз (миндалевидная
форма, как у старого маскота «Наглаз»), а внутри вместо привычного зрачка —
мини-граф из git: два коммита сходятся в один (слияние веток), финальный узел
подсвечен кольцом, как зрачок в фокусе. Не Octocat, не GitHub-логотип — свой
знак, узнаваемый в чёрно-белом виде.

Два акцентных цвета — как того требует бренд-гайд: янтарный контур глаза
(`--accent`) + индиго граф (`--accent-2`).

## Файлы

| Файл | Назначение |
|---|---|
| `icon-dark.svg` / `icon-dark-{512,1024,2048}.png` | Иконка на тёмной плашке `#0E1420` — аватар канала (TikTok/Telegram/YouTube), favicon |
| `icon-light.svg` / `icon-light-{512,1024,2048}.png` | То же на светлой плашке `#F5F1E8` — для светлых интерфейсов, мерча на светлом фоне |
| `lockup-dark.svg` / `lockup-dark-1400.png` | Знак + словесная часть «GitSight», прозрачный фон, для тёмных подложек (интро видео, тёмный сайт) |
| `lockup-light.svg` / `lockup-light-1400.png` | То же для светлых подложек |

PNG экспортированы через Playwright/Chromium из исходных SVG — при необходимости
пересобрать другие размеры, `.svg` — источник истины, PNG регенерируются.

## Известное ограничение

Словесная часть в `lockup-*.svg` пытается подключить шрифт **Unbounded** через
`@import` из Google Fonts; если во время рендера нет сети, используется системный
жирный sans-serif как фолбэк (так и получилось в текущих PNG — буквы читаются, но
не в фирменной геометрической гарнитуре). Если нужен точный шрифт — открыть SVG в
браузере с доступом в интернет и переэкспортировать, либо отрисовать вручную
у дизайнера/иллюстратора по гайду (`../brand-guide.md`, раздел 3.1).

## Что дальше

Иконка — рабочий, готовый к использованию вариант (аватарки, фавикон, водяной
знак на карточках). Маскот «Наглаз» с 4 эмоциями (раздел 5 бренд-гайда) как был
задуман для иллюстратора — отдельная, более сложная задача, в этот проход не
входит.
