# Тон голоса «Наглядно» — brand-voice.md

Файл читают Scriptwriter и Editor перед каждым материалом.

---

## 1. В одном предложении

Говорим как умный друг, который увидел крутую штуку и на кухне за минуту объясняет,
почему это меняет твою жизнь — без понтов и без лекции.

## 2. Три принципа

1. **Сначала выгода, потом технология.** Не «это LLM-агент с RAG», а «оно само
   отвечает на письма, а ты только проверяешь».
2. **Конкретика вместо превосходных степеней.** Не «революционный прорыв», а
   «раньше 2 часа — теперь 4 минуты».
3. **Уважай зрителя.** Он не глупый, он просто не обязан знать жаргон. Расшифровываем,
   не упрощаем до вранья.

## 3. Тон по шкалам

- Дружелюбный > нейтральный > официальный. **Берём дружелюбный.**
- Разговорный, но грамотный. Короткие фразы. Можно неполные предложения.
- Лёгкая ирония — да. Сарказм и высокомерие — нет.
- «Ты», не «вы». Без панибратства и молодёжного сленга ради сленга.
- Эмоция уместна: «честно, это жутковато», «вот это поворот». Не наигранно.

## 4. Формулы хука (первые 2 секунды)

Выбираем одну под материал:

- **Обещание результата:** «Это делает за 10 секунд то, на что уходил час.»
- **Разрыв ожидания:** «Ты думаешь, это видео сняли на камеру. Нет.»
- **Вопрос в лоб:** «Сколько ты платишь за [сервис]? Забудь.»
- **Было/стало:** «Слева — как делали в 2023. Справа — как сейчас.»
- **Личное:** «Я неделю пользуюсь этим вместо [X]. Рассказываю.»
- **Цифра:** «5 бесплатных штук, которые заменяют подписку за 2000 ₽.»

Запрещённые хуки: «В этом видео я расскажу…», «Подпишись, чтобы не пропустить…»,
«Всем привет, друзья», «ТОП-5 нейросетей 2026» (клише, режет доверие).

## 5. Расшифровка терминов (правило 4.6 бренд-гайда)

Термин на экране → сразу русская расшифровка в скобках, 1–2 слова, тем же кеглем.
Мини-словарь (дополняется):

| Термин | Расшифровка на экране |
|---|---|
| опенсорс / open-source | открытый код |
| инференс | запуск модели |
| локально / on-device | на твоём устройстве, без интернета |
| агент | ИИ, который сам выполняет действия |
| промпт | текстовый запрос |
| репозиторий / repo | папка с кодом проекта |
| форк | своя копия проекта |
| API | способ подключить одну программу к другой |
| токен | кусочек текста для модели ≈ 0.75 слова |
| файн-тюн | дообучение под задачу |
| эмбеддинг | перевод текста в числа для поиска по смыслу |
| латентность | задержка отклика |
| бенчмарк | стандартный тест для сравнения |

Если для термина нет короткой расшифровки — значит, тема слишком сложная для формата,
переупаковываем или отказываемся.

## 6. Словарь бренда

**Говорим:** штука, попробовать, пощупать, заменяет, бесплатно, за секунды,
на твоём устройстве, без регистрации, вот что умеет, куда это идёт.

**Не говорим:** «инновационный», «революционный», «game-changer», «на минималках»,
«имба», «ловите», «залетайте», «по красоте», «нейронка порвала», «GPT-убийца».

**Числа:** пишем цифрами (5, не «пять»), деньги с валютой и периодом (900 ₽/мес),
время экономии всегда конкретно (было X — стало Y).

## 7. Подписи и хэштеги

**Подпись (caption):** 1–2 строки. Первая = усиление хука или вопрос в аудиторию.
Вторая = «полная сборка и ссылка „пощупать“ в Telegram, @naglyadno_tech». Один эмодзи максимум.

Пример:
> Через год так будет отвечать на письма каждый.
> Все ссылки — в Telegram, ник в шапке. 👇

**Хэштеги:** 4–6 штук, смесь широких и нишевых, без «#рек #рекомендации #fyp» пачкой.
Базовый набор:
`#технологии #искусственныйинтеллект #нейросети #ии #технологиибудущего`
+ 1 тематический под материал (`#видеомонтаж`, `#приватность`, `#дизайн` …).

**YouTube Shorts:** тот же текст, хэштеги в описание, первые 100 символов = хук.

## 8. Длины

| Формат | Длина |
|---|---|
| Видео-ролик (ИИ-факт, до/после) | 20–35 сек, идеально 24 |
| Карусель | 5–7 слайдов |
| Закадровый текст | ≤ 55 слов на 20 сек (темп ~2.7 слова/сек) |
| Подпись | ≤ 200 знаков |
| Заголовок слайда | ≤ 7 слов |

## 9. Этика и факты

- Не преувеличиваем возможности. Если демо черрипикнутое — говорим «в рекламе всё гладко,
  на практике бывают осечки».
- Указываем, если проект платный / в закрытой бете / требует VPN.
- Не выдаём чужие демо за свои: «видео из репозитория проекта».
- Приватность: если инструмент шлёт данные на сервер — говорим об этом прямо.
- Не даём финансовых и медицинских советов, даже если инструмент про это.
- Спорные прогнозы в «Через год» помечаем интонацией мнения, не факта.
