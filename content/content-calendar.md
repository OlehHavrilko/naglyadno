# Контент-календарь «Наглядно»

Агент читает этот файл ПЕРЕД каждым циклом. Правило: не брать тему, если её корень
(проект/сервис/факт) уже встречается в колонке «Тема» за последние 30 дней или стоит
в «Запланировано». После публикации строка переносится в `published-log.csv`.

Рубрики (коды): `PD` — проект дня · `F20` — ИИ-факт за 20 сек · `BA` — до/после ·
`ALT` — 5 бесплатных альтернатив · `VIR` — разбор вирального · `MEM` — мем + факт.

Темп: 3–5 публикаций в неделю. Ротация рубрик за неделю: минимум 3 разные.

## Пул идей (не разобраны, для Editor)

- Оффлайн-переводчик с камеры телефона — до/после с бумажным разговорником.
- Генерация 3D-модели из одной фотографии — PD.
- ИИ читает рукописный текст врача — F20 / до-после.
- «5 бесплатных нейро-фоторедакторов» — ALT.
- Как работает поиск по смыслу (эмбеддинги) на пальцах — F20.
- Восстановление старых фото семьи — BA, сильная эмоция.
- Клонирование голоса за 10 секунд: где это уже проблема — VIR + этика.
- Локальный поиск по всем своим файлам «своими словами» — PD.
- ИИ-субтитры к любому видео офлайн — ALT / PD.
- «Через год у каждого будет свой…» — рекуррентная рубрика-прогноз.

## Правила отбора (напоминание для агента)

1. Чип «Врубишься за» ≠ 🟠; если 🟠 (надо вникнуть) — только при сильном вау-эффекте.
2. Есть что показать: демо / скриншот / до-после. Нет визуала — нет темы.
3. Проверить `published-log.csv` на повтор корня темы за 30 дней.
4. Не больше одной «тяжёлой» темы (приватность, этика, экология) в неделю.
5. Каждый материал: слайд «что заменяет» + слайд «через год» + «пощупать за 30 сек».
