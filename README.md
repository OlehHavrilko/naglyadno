# «Наглядно» — канал про интересные технологии и ИИ

Рабочее имя проекта. Канал в TikTok / Reels / Shorts про технологические и AI-проекты,
понятные широкой аудитории за 3 секунды просмотра. Не «инструменты для разработчиков»,
а «смотри, что оно умеет и куда катится мир».

Собрано по брифу `tiktok-channel-brief.md`. Три блока, в порядке готовности:

| Блок | Где | Статус |
|---|---|---|
| 1. Бренд-гайд | `brand/brand-guide.md`, `brand/brand-voice.md`, `brand/tokens.css` | готово, черновик v0.1 |
| 2. Пилот контента | `content/pilot/` (8 материалов, 4 рубрики) | готово, к съёмке/вёрстке |
| 3. Пайплайн-агент | `agent/PIPELINE.md` + роли `agent/01…05` | готово, полуавтомат с ревью |
| Движок карточек | `cards/template.html` | готово, открывается в браузере |
| Автопайплайн | `ARCHITECTURE.md`, `src/`, `n8n/`, `docker-compose.yml` | рабочий скелет: n8n + Node-сервер, рендер PNG проверен |

## Автопайплайн (код)

Полу-/полностью автоматический конвейер: тренды → сценарий → слайды PNG → карусель в TikTok.

| Файл | Что |
|---|---|
| `SETUP.md` | установка, какие ключи завести, первый прогон |
| `ARCHITECTURE.md` | как устроен пайплайн, схема стадий, модули |
| `src/` | Node-проект: `cycle.js` + стадии `stages/01…06`, рендер, публикация |
| `n8n/` | workflow-планировщик (`naglyadno-workflow.json`) |
| `.env.example` | все ключи с ссылками, где взять |

Быстрый старт (нужен свежий терминал с `node -v` → v24):

```
cd D:\claude\naglyadno
npm run render:demo     # проверка рендера, без ключей → agent/output/demo-render/
npm run cycle full      # весь цикл (нужны ключи в .env, см. SETUP.md)
```

Ревью материала приходит в Telegram с кнопками «Постить / Скип».
`AUTO_PUBLISH=true` в `.env` — полный автомат без подтверждения.

## Про имя

Бриф рекомендовал «Апгрейд» / «Синтаксис». По твоему запросу подобран новый нейминг.
Рабочий выбор — **«Наглядно»**: одно слово, произносится без запинки не-технарём,
прямо кодирует обещание канала (понял быстро, увидел наглядно), тянется на любую
тему — гаджеты, ИИ, софт, «как это работает». Не привязано к формату «топ репозиториев».

Запасные, если занято на нужных платформах (порядок = моё предпочтение):

| Имя | Идея | Тон |
|---|---|---|
| **Штука** | «смотри какая штука», «что за штука» — любопытство | разговорный, широкий |
| **Рубильник** | «врубить / врубиться» — понять и включить | энергичный, тактильный |
| **Прошивка** | «прошивка мозга / реальности» | техно, но не тяжёлый |
| **Ого** | буквально вау-эффект, ультра-короткое | эмоциональный, минимал |

Всё в проекте написано так, чтобы имя менялось поиском по строке `Наглядно` /
`naglyadno`. Токен бренда в карточках — переменная `--brand-name`.

## Что отличает канал (фирменные фишки)

Полное описание — в `brand/brand-guide.md`, раздел 4. Коротко, шесть повторяющихся
механик, которых нет у трёх каналов-референсов:

1. **Чип «Врубишься за»** — на каждой карточке проекта плашка со шкалой понятности:
   🟢 3 сек / 🟡 15 сек / 🟠 надо вникнуть. Обещание «за 3 секунды» становится видимым штампом бренда.
2. **Что это заменяет** — фиксированное поле: какую платную услугу / привычку / рутину
   проект убирает из жизни обычного человека. Потребительский угол вместо «фич».
3. **Через год** — финальный слайд с одной дерзкой строкой-прогнозом «к чему это
   приведёт». У канала появляется позиция и повод для спора в комментах.
4. **Пощупать за 30 секунд** — в конце каждого материала один самый быстрый способ
   попробовать самому прямо сейчас (ссылка / приложение / промпт), не «склонируй репозиторий».
5. **Разбор одним кадром** — второй слайд карусели всегда «как это работает» в одной
   подписанной картинке. Её можно репостить отдельно, и она всё объясняет.
6. **Ноль англицизмов без перевода** — любой неизбежный термин получает на экране
   русскую расшифровку в 2 слова. Это само по себе узнаваемый почерк.

Маскот **«Наглаз»** (глаз-объектив, свой, не Octocat) — узнаваемый бренд-элемент,
3 настроения (спокойный / удивлённый / восторг), ставятся по смыслу кадра.

## Как пользоваться агентом

Перед каждым циклом агент читает `content/content-calendar.md` и
`content/published-log.csv`, чтобы не повторять темы. Дальше по ролям:
Trend Scout → Editor → Scriptwriter → Visual Producer → Publisher & Tracker.
На старте — с твоим ревью после каждого шага. Детали и промпты — в `agent/`.

## Ближайшие шаги

1. Утвердить имя и палитру, при желании — заказать маскота у иллюстратора по описанию
   в `brand/brand-guide.md`.
2. Снять / сверстать пилот (8 материалов), выложить 3–5 раз в неделю две недели.
3. Прогнать агента на живом цикле, занести метрики в лог, на разборе через неделю
   отсечь слабые рубрики.
