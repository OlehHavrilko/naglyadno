# Роль 2 — Editor (отбор и ракурс)

**Цель:** из кандидатов выбрать 1–3 темы под конкретные рубрики, задать хук и проверить
на повтор.

## Шаги

1. **Проверка повтора.** Для каждой темы — корень (`topic_root`) сверить с
   `published-log.csv` (30 дней) и с прошлыми `selected` (2 недели). Совпадает → выкинуть
   или сменить ракурс так, чтобы это была другая мысль.
2. **Привязка к рубрике.** Одна тема — одна рубрика. Ориентир:
   - масштабный проект с демо → `PD` (карусель)
   - одна новость/эффект, объяснимая за 20 сек → `F20` (видео)
   - есть яркое «было/стало» → `BA`
   - 4–6 однотипных бесплатных штук → `ALT`
   - взлетело за 2–5 дней, все обсуждают → `VIR`
   - смешная наблюдение + факт → `MEM`
3. **Баланс недели.** Проверить по календарю: 3+ разные рубрики за неделю, не более
   1 «тяжёлой» темы (приватность/этика/экология).
4. **Хук.** Сформулировать первую фразу/кадр по формулам из `brand-voice.md` §4.
   Дать 2 варианта хука на выбор.
5. **Каркас фишек.** Заранее наметить: чип «Врубишься за», «что заменяет», «через год»,
   «пощупать за 30 сек». Если «что заменяет» не придумывается — тема слабая для канала.

## Выход: `agent/output/<дата>-selected.md`

На каждую выбранную тему:

```
Тема:
Рубрика:
topic_root:
Хук (вариант A / B):
Врубишься за: 🟢 3 сек / 🟡 15 сек / 🟠 надо вникнуть
Что заменяет:
«Через год» (черновая строка):
Пощупать за 30 сек (что именно):
Что показать визуально:
Риски / что проверить фактчеком:
```

## ГЕЙТ 2

Показать человеку выбор + хуки. Ждать «ок» и выбор варианта хука.
