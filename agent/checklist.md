# Чек-лист цикла «Наглядно» (один проход)

## Перед стартом
- [ ] Прочитаны `brand/brand-guide.md`, `brand/brand-voice.md`
- [ ] Прочитаны `content/content-calendar.md`, `content/published-log.csv`
- [ ] Ясно, сколько материалов готовим (1–3) и под какие рубрики

## Trend Scout → ГЕЙТ 1
- [ ] Обойдены все источники из `agent/01-trend-scout.md`
- [ ] 5–10 кандидатов, у каждого: простое описание, ссылка, «что показать», понятность (🟢/🟡/🟠)
- [ ] Каждый прошёл 5 критериев отбора
- [ ] Файл `agent/output/<дата>-candidates.md` создан
- [ ] Человеку показана таблица + топ-3, получен выбор

## Editor → ГЕЙТ 2
- [ ] Проверка повтора по `topic_root` (30 дней + 2 недели selected)
- [ ] Каждой теме назначена ровно одна рубрика
- [ ] Баланс недели: 3+ рубрики, ≤1 «тяжёлая» тема
- [ ] Готовы 2 варианта хука на тему
- [ ] Намечены чип «Врубишься за» / что заменяет / через год / пощупать
- [ ] Файл `agent/output/<дата>-selected.md` создан
- [ ] Человек выбрал темы и вариант хука

## Scriptwriter → ГЕЙТ 3
- [ ] Текст в голосе бренда, запрещённых слов/хуков нет
- [ ] Все термины с расшифровкой
- [ ] Заголовки ≤ 7 слов, одна мысль на слайд, закадр в темпе
- [ ] Есть блоки «что заменяет» и «через год»
- [ ] «Пощупать за 30 сек» с проверенной живой ссылкой
- [ ] Для карусели — слайд 02 «разбор одним кадром» самодостаточен
- [ ] Подпись + 4–6 хэштегов
- [ ] Фактчек-строка с источниками
- [ ] Файл `content/pilot/<id>-<RUBRIC>-<slug>.md` с YAML-заголовком

## Visual Producer → ГЕЙТ 4
- [ ] Карусель: слайды собраны в `template.html`, экспорт PNG 1080×1350
- [ ] Видео: storyboard.md / vo.txt / titres.txt / assets.md + intro/outro PNG
- [ ] Палитра из `tokens.css`, ≤2 акцента на экран, поля и нижние 160 px соблюдены
- [ ] Маскот с нужной эмоцией
- [ ] Чужие ассеты подписаны источником
- [ ] Папка `agent/output/<дата>-<slug>/` + preview
- [ ] Человек одобрил превью

## Publisher & Tracker → ГЕЙТ 5
- [ ] `PUBLISH.md` собран (медиа, подписи, хэштеги, закреп-коммент, Telegram-пост)
- [ ] Рекомендованное время указано
- [ ] Строка в `content-calendar.md` обновлена
- [ ] Человеку передан пакет
- [ ] После публикации: строка в `published-log.csv`, через 48–72 ч — метрики
- [ ] В конце недели — `agent/output/<неделя>-review.md`
