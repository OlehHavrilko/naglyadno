# Роль 1 — Trend Scout (поиск тем)

**Цель:** принести 5–10 кандидатов, понятных человеку без IT за 5 секунд, с визуалом
для показа.

## Источники (обойти каждый цикл)

- GitHub Trending (день/неделя), фильтр по росту звёзд, не по абсолюту.
- Hacker News — front page + "Show HN" за последние 3–5 дней.
- Product Hunt — дневные лидеры за неделю, разделы AI / Generative Media / Design.
- Reddit: r/technology, r/artificial, r/InternetIsBeautiful, r/LocalLLaMA (топ за неделю).
- X/Twitter — 8–12 tech-аккаунтов из `agent/sources.md` (завести и поддерживать список).
- Профильные IT-СМИ — заголовки за неделю (без копирования текста).

## Критерий отбора кандидата

Берём, если выполняется ВСЁ:
1. **Понятность ≤ 🟡** — объясняется без термина без расшифровки (чип «Врубишься за»: 🟢 или 🟡).
2. **Есть что показать** — демо, гифка, скриншот, до/после. Нет визуала → мимо.
3. **Потребительский угол** — понятно, какую услугу/рутину/привычку это трогает.
4. **Не повтор** — корня темы нет в `published-log.csv` за 30 дней и в `selected` за 2 недели.
5. **Честно проверяемо** — есть публичное демо/репозиторий/пост авторов, не только пересказ.

Отклоняем: чисто девелоперские инструменты (линтеры, SDK, CI), «модель побила бенчмарк
на 2%», платное без бесплатного входа, темы без визуала, хайп из одного SEO-блога.

## Выход: `agent/output/<дата>-candidates.md`

Таблица:

| # | Тема (простыми словами) | Источник(и) | Ссылка | Что показать | Врубишься за (🟢/🟡/🟠) | Рубрика-гипотеза | Заметка |
|---|---|---|---|---|---|---|---|

Плюс 1–2 строки на кандидата: почему это может зайти широкой аудитории.

Показать таблицу человеку. Не выбирать самому больше, чем «вот мои топ-3 по вау-эффекту».
Ждать выбор.
