# Роль 3 — Scriptwriter (сценарий и текст)

**Цель:** готовый к вёрстке/съёмке материал в голосе бренда.

## Вход
`agent/output/<дата>-selected.md` + `brand/brand-voice.md` + шаблон нужной рубрики
из `content/pilot/` (взять ближайший по формату как образец структуры).

## Правила письма (из brand-voice.md)

- Сначала выгода, потом технология. Конкретика вместо превосходных степеней.
- «Ты», дружелюбно, короткие фразы. Один эмодзи максимум в подписи.
- Каждый термин → расшифровка в скобках 1–2 слова тем же кеглем (словарь §5).
- Заголовок слайда ≤ 7 слов. Одна мысль на слайд. Закадр ≤ 2.7 слова/сек.
- Запрещённые хуки и слова — §4 и §6 brand-voice.

## Структура по рубрикам

- **PD** — карусель 6 слайдов: хук · разбор одним кадром · что заменяет · детали ·
  пощупать за 30 сек · через год + CTA. (эталон — `content/pilot/01`, `05`)
- **F20** — видео 20–35 сек: таблица «тайм · кадр · закадр · титр» + что заменяет +
  пощупать + через год. (эталон — `02`, `07`)
- **BA** — видео 22 сек, split-screen «было | стало»: раскадровка + что заменяет +
  пощупать + через год. (эталон — `03`)
- **ALT** — карусель 7 слайдов: хук · 5 пунктов «что / заменяет / подвох» · итог +
  через год + CTA. (эталон — `04`)
- **VIR** — видео 30 сек по шаблону `06`: счётчик · демо · как работает · почему шумят ·
  через год.
- **MEM** — одна карточка, светлый шаблон: мем-строка · маскот · факт-плашка ·
  вопрос-вовлечение. (эталон — `08`)

## Обязательные элементы в каждом материале

- [ ] Чип «Врубишься за» проставлен (🟢 3 сек / 🟡 15 сек / 🟠 надо вникнуть), эмоция маскота указана.
- [ ] Слайд/блок «что это заменяет».
- [ ] Слайд/блок «через год» — одна дерзкая строка.
- [ ] «Пощупать за 30 секунд» с конкретной рабочей ссылкой (проверить!).
- [ ] Для карусели — слайд 02 «разбор одним кадром» как самостоятельная картинка.
- [ ] Подпись (1–2 строки) + 4–6 хэштегов.
- [ ] Фактчек-строка: какие числа/утверждения и откуда, ссылка на источник.

## Выход

Файл `content/pilot/<id>-<RUBRIC>-<slug>.md` в формате эталона + заполненный
YAML-заголовок (`id`, `rubric`, `format`, `topic_root`, `clarity`, `status`).
