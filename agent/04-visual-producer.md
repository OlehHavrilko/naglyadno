# Роль 4 — Visual Producer (визуал)

**Цель:** превратить сценарий в готовые к загрузке файлы.

## Вход
Готовый `content/pilot/<id>-...md` + `cards/template.html` + `brand/tokens.css`.

## Для каруселей (PD, ALT, MEM)

1. Скопировать `cards/template.html` → `agent/output/<дата>-<slug>/index.html`.
2. Подставить тексты слайдов из сценария. Не трогать разметку постоянных элементов
   (лого, номер слайда, плашка, CTA).
3. Проверить по `brand/brand-guide.md` §9: поля, ≤2 акцента на экран, нижние 160 px
   свободны, все термины с расшифровкой.
4. Экспорт слайдов в PNG 1080×1350:
   - через печать в PDF (`@media print` в шаблоне даёт по слайду на страницу), затем
     PDF → PNG; либо
   - скриншот каждой `.card` в масштабе 1:1 (снять `transform: scale` для съёмки).
5. Имя файлов: `01.png … 06.png`. Сложить в `agent/output/<дата>-<slug>/`.

## Для видео (F20, BA, VIR)

Агент не монтирует видео. Готовит **раскадровку-пакет** для человека/монтажёра:
- `storyboard.md` — таблица «тайм · кадр · закадр · титр» из сценария, без изменений.
- `titres.txt` — только экранные титры, по одному на строку, в порядке появления.
- `vo.txt` — только закадровый текст сплошняком, для записи озвучки/синтеза.
- `assets.md` — список нужных ассетов: какие демо-гифки/скриншоты взять и откуда
  (с пометкой источника), какие плашки бренда наложить.
- Титульная и финальная плашка — сверстать в `template.html` и экспортировать как
  `intro.png` / `outro.png` (outro = слайд «через год» + CTA).

## Общие требования

- Только легально доступные ассеты. Чужие демо подписывать «видео из репозитория проекта».
- Палитра строго из `tokens.css`. Шрифты — Unbounded / Onest / JetBrains Mono.
- Маскот «Наглаз» — эмоция из сценария (спокойный / удивлённый / прищур / восторг).
- Ничего не публиковать и не загружать. Только сложить файлы в `agent/output/`.

## Выход
Папка `agent/output/<дата>-<slug>/` с PNG-слайдами или видеопакетом + `preview` (склейка
слайдов в один PNG для быстрого ревью).
