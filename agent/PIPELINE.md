# Пайплайн-агент «Наглядно»

Один агент проходит пять ролей последовательно за цикл. На старте — полуавтомат:
после каждой роли агент останавливается и ждёт ревью человека (`ГЕЙТ`).

```
Trend Scout → [ГЕЙТ 1] → Editor → [ГЕЙТ 2] → Scriptwriter → [ГЕЙТ 3]
   → Visual Producer → [ГЕЙТ 4] → Publisher & Tracker → [ГЕЙТ 5: человек публикует]
```

## Обязательное чтение перед КАЖДЫМ циклом

1. `brand/brand-guide.md` — позиционирование, фишки, визуал, что нельзя.
2. `brand/brand-voice.md` — тон, хук-формулы, словарь терминов, длины.
3. `content/content-calendar.md` — что запланировано и в пуле идей.
4. `content/published-log.csv` — что уже выходило (проверка повторов за 30 дней).

## Артефакты цикла

| Роль | Вход | Выход |
|---|---|---|
| Trend Scout | источники + лог | `agent/output/<дата>-candidates.md` (5–10 тем) |
| Editor | candidates | `agent/output/<дата>-selected.md` (1–3 темы с ракурсом и хуком) |
| Scriptwriter | selected + brand-voice | `content/pilot/<id>-<rubric>-<slug>.md` (готовый сценарий) |
| Visual Producer | сценарий + `cards/template.html` | папка `agent/output/<дата>-<slug>/` со слайдами (PNG) или раскадровкой |
| Publisher & Tracker | готовый пакет | строка в `content/content-calendar.md` → после публикации в `published-log.csv` |

## Правила гейтов

- Агент НЕ переходит к следующей роли без явного «ок» от человека.
- На гейте агент показывает: что сделал, где лежит, что осталось решить человеку.
- Если человек молчит — агент не публикует и ничего не отправляет наружу.

## Частота

3–5 материалов в неделю. За неделю минимум 3 разные рубрики. Один цикл готовит
1–3 материала. «Тяжёлые» темы (приватность, этика, экология) — не больше 1 в неделю.

## Границы (важно)

- Агент готовит пакет, но **публикует человек** вручную в приложении. Официального
  публичного API для обычных TikTok-аккаунтов нет.
- Агент не отправляет сообщения, не постит и не регистрирует аккаунты сам.
- Любые внешние ссылки в материале — проверены агентом на «живость» и указаны явно.
- Цифры и факты — с источником. Нет источника → формулировка «по разным оценкам» или тема снимается.
- Веб-поиск — только для Trend Scout и проверки фактов, не для копирования чужих текстов.

## Запуск (пример для Claude Code)

> Прочитай `brand/`, `content/content-calendar.md`, `content/published-log.csv`.
> Выполни роль Trend Scout по `agent/01-trend-scout.md`. Останься на ГЕЙТ 1:
> покажи 5–10 кандидатов таблицей и жди моего выбора.
